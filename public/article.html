标题：把全班的去向，画在一幅地图上

作者：零本

山川异域，风月同天。

今天，我正式推出「蹭饭图生成器」——一个把全班同学的去向画在中国地图上的小工具。输入姓名、大学和城市，一幅属于你们班的蹭饭图即刻生成：谁去了哪座城市、哪所高校，一目了然。

做它的原因很简单。录取结果陆续公布，几十个朝夕相处的人，即将散落到大半个中国。散场之前，总该留下一张像样的图——以后走到哪座城市，翻开它，就知道该敲谁的门、蹭谁的饭。

即日起，打开 map.linkbrain.top 即可免费使用：无需注册，没有广告，所有数据只保存在你自己的浏览器里。

示例：一幅 23 人的蹭饭图，15 个省级行政区、15 座城市（图中人物均为虚构）

■ 三分钟，从零到一幅图

整个流程只有三步：录入名单 → 调整样式 → 导出图片。

名单有两种录入方式。人少，就逐条手动填；人多，下载 Excel 模板批量填好再导入——导入前会先让你预览解析出的每一行，确认无误后再选择追加或替换。填完大学名，城市会自动补全，也可以再用「省份 → 城市」两级下拉精调——全国每一个地级市都在库里，坐标由服务端按需查询，不用一次性加载。

推荐在电脑上录入和生成，效率最高；手机端同样有完整的录入界面，适合随时补充。

录入面板：名单按省份分组，与地图标注严格一致

■ 七套主题，一键换气质

同一份名单，可以是暖阳的喜庆，也可以是水墨的克制。内置七套预设主题：暖阳金、海阔天空、青山墨绿、朱砂喜庆、极简灰白、活力卡通、水墨丹青，点击即切换，画布实时重绘。

预设都不满意，还可以逐项自定义：画布底色、省份填充、标题色、标注色、引线色，全部开放。调出来的配色会自动存为「自定义」主题，下次打开还在。

同一份名单 × 三套主题：暖阳金 / 海阔天空 / 水墨丹青

■ 字体，细到每一个模块

大多数工具只让你选一种字体。这里不是。标题拆成数字、英文、中文三个槽位，地图标注拆成省份名、姓名、城市与大学三个槽位——六个槽位各自独立设置字体和字号。年份可以用阿里妈妈数黑体的锋利，人名用思源黑体的干净，省份名用马善政毛笔体的洒脱，互不干扰。

预设字体全部免费可商用；有特殊偏好，也可以上传自己的字体文件（仅保存在本机浏览器）。

这个面板里还有一个开关：校徽图片。喜欢纯粹的文字排版，关掉它，地图上的校徽就会整体隐去。

字体设置：三个标注槽位独立调节，底部是校徽开关

■ 校徽自动匹配，也可以为每个人单独定制

填完大学名，校徽会自动出现在名字前面。校徽图库覆盖八百余所高校，经本站服务器代理加载并缓存，第二次打开几乎瞬时。

如果自动匹配不合心意，每一个人都可以单独定制：上传自己准备的校徽图片替代默认的，或者只把某一个人的校徽隐藏起来——在录入面板里点校徽图标就能设置，全局开关管整体，个人设置管例外。

■ 校名，可以写成毛笔字

这是我最喜欢的功能。任何一所大学，都可以上传一张你自备的透明底横版毛笔字图片——找班里写字最好的同学题一幅，或者从学校官微取一张官方题字。上传后，地图上的大学文字将被这幅墨迹替代：校徽在前，笔意随后，大小用滑块自由调节。上面那幅示例图里，「西安电子科技大学」就是毛笔字渲染的。一幅蹭饭图，从此有了人情味。

■ 为五十个人设计的排版引擎

蹭饭图最难的不是画地图，是把几十个人的名字摆好看。这里的标注列按地理方位自动排布：北方的省份排在上方，南方的沉到下方，西部居左、东部居右，引线自然就少了交叉。引线也不是生硬的直线，而是从定位点到标注块的贝塞尔曲线，弧度自然。

校名再长也不省略、不缩字号，而是自动换行——「林栖迟 清华大学 · 北京」必须完整，这是底线。同一个省的多名同学，默认按软科中国大学排名排序；想按自己的心意排，拖动或点按调整之后，这个省会记住你的手动顺序。

老师名单可选填，会在画布角落生成「相伴三年的老师们」卡片；标题可以居左、居中、居右，也可以加一行英文副标题。

■ 超清导出，为打印而生

导出与屏幕分辨率无关。哪怕你的显示器只有 1080p，导出的 PNG 宽度也不低于 4000 像素——打印、装裱、在班级群里放大看细节，都够用。

导出过程有实时进度条和预计剩余时间，长任务也不会让人心里没底。名单本身还能导出成 Excel 或 JSON 备份；配合多画布功能，一个班可以做好几幅不同风格的图，各自独立保存，随时回来修改。

导出超清 PNG：实时进度与剩余时间预估

电脑端编辑器：左侧控制台，右侧地图实时联动

■ 手机端：随时补录，生成请回电脑

手机端有「录入 / 地图 / 关于」三个 Tab，界面为小屏重新排布：姓名、校名各自独占一行，排序改成上下按钮，名单面板从屏幕中央弹出。聚餐时突然想起谁漏了，掏出手机就能补上。

但有一句实话放在这里：手机端适合录入，生成图片请尽量回电脑。大屏排版，所见即所得，导出的图也更可靠。

手机端：录入 / 地图 / 关于三个 Tab，随时补充名单

■ 你的名单，只在你手里

这个工具没有账号体系，也不要求你上传任何名单到服务器。所有数据都保存在你自己浏览器的本地存储里，刷新不丢失，换台电脑可以用 JSON 导出导入带走。服务器只做两件事：查询城市坐标、代理校徽图片。
