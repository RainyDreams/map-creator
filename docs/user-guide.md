# 使用教程

本教程带你从零做出一张精美的班级蹭饭图。全程在浏览器完成，**无需注册、数据只保存在你自己的设备上**。

> 图中姓名均为虚构示例，并开启了「名字一键隐私」（显示为「姓+同学」）。

## 一、三分钟快速上手

打开 [map.linkbrain.top](https://map.linkbrain.top)，整个页面就是一个「创建器」：

- **电脑端**：左边是录入面板，右边是地图预览，录入时地图实时联动；
- **手机端**：底部有「录入 / 地图 / 关于」三个 Tab，随时切换。

![桌面端创建器](images/02-entry-desktop.png)

最快的路径只有三步：

1. 在「班级信息」里写好**大标题**（如 `2026届 高三（2）班蹭饭图`）；
2. 在「学生名单」里点「编辑名单 / 添加同学」，把同学们的**姓名、大学、城市**填进去；
3. 切到地图，点右上角黑色按钮「**导出为图片**」，选「超清」，完成。

## 二、录入名单

### 手动录入

点击「编辑名单 / 添加同学」打开录入面板。名单**按省份分组**，和地图上的标注一一对应：

- 每位同学三个字段：**姓名、大学、城市**；
- 城市支持**省/市两级下拉选择**，精确到全国每一个地级市；
- 大学填好后，系统会尝试**自动推断城市**（预设院校库 + 校名中的地名匹配），推断错了随时可以手动改；
- 拖动行首的手柄可以调整组内顺序（调整后该省保持手动顺序，不再按软科排名自动排）。

![学生名单录入面板](images/03-student-modal.png)

### Excel 批量导入（推荐人数多时使用）

1. 点顶部「**导入**」（或学生名单区的「上传 Excel 名单」）；
2. 在弹窗里**下载模板**（黑底按钮，包含「姓名」「大学」两个预设列）；
3. 用 Excel / WPS 填好后上传——导入前可以**预览**，并选择**追加**还是**替换**现有名单。

> 文件编码已做兼容处理，Excel 直接另存的 `.xlsx` 不会有乱码问题。

### 特殊情况

- **境外同学**：勾选该同学行的「境外」，城市栏改填国家/地区（如「美国」「新加坡」）。TA 不会指向中国地图，而是在右下角「海外 / 境外的同学们」区块单独列出；
- **老师名单**：可选填，标题可自定义（默认「相伴三年的老师们」），也可整体关闭显示；
- **录取专业与高考分数**：打开学生名单区的「录入更详细的信息」开关，每位同学可补充专业与分数（留存在数据中，可按需显示上图）；
- **只显示省份**：在排版设置中开启后，地图上学生行不显示城市，录入时也可以只选省份不选市。

## 三、排版设计

### 主题与颜色

- 「画布风格」提供多套预设主题，也可以完全自定义配色；
- 「**省份颜色**」面板可以为每个省单独定义地图填色：
  - **有同学的省份**：默认跟随主题色板循环，可单独改色（不影响其他省的配色顺序）；
  - **没有同学的省份**：三种状态任选——保持默认底色 / 按主题自动填充 / 自定义颜色。

![省份颜色面板](images/04-province-color.png)

### 省份卡片的四种排布

| 模式 | 效果 |
| --- | --- |
| 一列（默认） | 名单卡片在地图左右两侧各排一列 |
| 两列 | 人多时更宽松，左右各两列 |
| 竖版排版 | 所有卡片集中在地图下方，按行流式排布 |
| 自定义位置 | 自由拖动每张卡片，拖到哪儿算哪儿 |

使用技巧：

- **拖动即自定义**：在「一列/两列/竖版」任意模式下拖动卡片，会自动切换到自定义模式（从当前位置开始，不会跳变）；切回一列/两列时自定义偏移会重置；
- **画布自适应**：卡片拖到边缘，画布会自动扩大；拖回来，画布自动缩小——左右留白不必对称；
- **对齐辅助**：拖动时出现对齐参考线，5px 误差内自动吸附；
- **点选置顶**：点击哪张卡片，哪张卡片层级上移，避免被遮挡；
- 人特别多（如全省 20 人）时，可以在录入面板把**一个省拆成多张卡**，甚至按城市拆卡，卡片之间的人员可以互相拖动；
- 「统一卡片宽度」可让所有卡片与最宽的一张同宽。

### 字体与字号

- 标题（数字/英文/中文）、省份名、姓名、城市大学、老师名单均可**独立设置字体与字号**；
- 预设多款开源字体（按需子集化加载，只下载用到的字符），也可**上传自己的字体**；
- 字号拿不准时，设置项旁边会出现**行内推荐标注**（如「推荐 16px」），点击即可应用——推荐算法按地图空间与名单长度计算，不会弹窗强迫你。

### 卡片样式

背景开关、圆角大小、卡片颜色（可透明）、不透明度、边缘羽化、文字左/右对齐（每张卡可单独设置）、人数统计小块（默认关闭，可开在卡片内角落）。

## 四、个性化装饰

- **班徽/校徽**：班级信息里上传，显示在标题区，大小可调；
- **毛笔字图片**：为某所大学上传透明底横版 PNG，地图上该校名字会被图片替代——毕业纪念册质感的关键；
- **校徽图片**：在学生名单里为每位同学手动上传校徽、单独隐藏或调整个大小；
- **同校合并**：同一大学的多名同学姓名一人一行，右侧只显示一次校徽与校名，学校之间以虚线分隔；
- **装饰元素**：在画布任意位置添加文本框与图片（调整位置/字号/颜色/宽度），用来装饰留白处；
- **名字一键隐私**：地图与导出图片中只显示「姓+同学」，原始名单仍完整保留在本机——发群、发朋友圈前建议打开。

## 五、导出与分享

### 导出高清 PNG

点「导出为图片」，选择清晰度后生成。**「超清」固定输出 4000px 宽**——无论你的屏幕分辨率多低，导出的都是高清图。

- 导出过程有进度条与预计剩余时间，可随时点红色按钮**取消**；
- 导出的图片右下角带 `map.linkbrain.top` 小水印（大小随画布比例缩放，无背景色，颜色跟随主题）；
- **微信里无法直接下载图片**：系统会自动弹出预览窗，**长按图片保存**即可（iPad 等平板同样走预览弹窗）。

## 六、多设备与备份

你的数据默认只存在本机浏览器里。换电脑、换手机、换浏览器，用「**ZIP 全量备份**」：

1. 旧设备：「导出」→「导出为 ZIP」——包含名单、主题字体等全部设置、每张卡片的位置、所有上传的图片（班徽/毛笔字/校徽/装饰）；
2. 新设备：「导入」→「导入 ZIP」——完整还原，分毫不差。

也可以只导出 JSON 数据文件做轻量备份。

## 七、常见问题

**Q：我的名单数据会上传到服务器吗？**
不会。所有名单数据保存在你自己浏览器的 localStorage 里，清除浏览器数据会丢失——重要作品请及时用 ZIP 备份。

**Q：多少人用一张图合适？**
50 人以内都很从容。单侧名单超过地图纵向高度约 1.1 倍时，系统会在「每侧标注列数」旁给出「建议两列」的行内推荐。

**Q：导出失败/卡住了怎么办？**
先看导出框中的阶段提示与控制台日志；仍失败时页面会出现错误横幅，点「反馈问题」一键提交（可选择附带本次会话日志——日志只在服务端保留约一周，且不含名单数据），一般两天内会有回复。

**Q：地图上的定位准吗？**
城市定位精确到地级市坐标（接口数据），接口不可用时回退到省份质心。地图为国家版图示意图，仅用于标注示意，不代表高校实际校址。

**Q：可以商用吗？**
本工具免费供毕业生个人使用。源码公开仅供学习参考，二次开发或商用请先联系作者。
